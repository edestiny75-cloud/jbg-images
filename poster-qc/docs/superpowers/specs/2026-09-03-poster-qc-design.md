# Poster QC — Design Spec (2026-09-03)

## Problem

JBG posters are generated by AI image models (Higgsfield Nano Banana Pro, ChatGPT/OpenAI). The models
misspell words, garble names, and drop letters ("Pennsylvaia", "Everest" for "Everett", "UAEMFLOYNENT").
Finding these by eye is slow and unreliable, and asking an AI model to re-render the poster with the fix
often does not land the fix or quietly breaks something else. The April medical round and the September
civics round both showed the same pattern: two AI edit passes failed; a pixel-level "locate, erase,
redraw in matched font" pass landed on the first try.

## Goal

A program that takes a poster file (PDF, PNG, or JPG), finds every text error, fixes each one with the
least invasive method that works, verifies the fix landed, and produces a clean file plus a report. Runs
on one file or a whole folder. Auto-fix and auto-verify by default; only stops for a human when it cannot
get a fix to pass the style gate after three rounds.

## Truth source for "content is right"

Spelling + grammar + facts against general knowledge + internal consistency + layout + JBG guardrail
phrasing. An optional instructions file (the `FIX_INSTRUCTIONS.md` style, `"wrong" → "right"` lines) is
merged in as known errors that must be found and fixed.

## Architecture

Python package `poster_qc` in this project folder, one CLI entry point.

```
poster_qc/
  cli.py            run <file|folder> [--out DIR] [--instructions MD] [--no-fix] [--max-rounds 3] [--model ID]
  config.py         API key loading (env → poster_qc/.env → Windows user registry), model id, paths
  ingest.py         PDF/PNG/JPG → PIL RGB at native resolution (PDF rasterized at 300 dpi per page)
  tiles.py          overlapping grid tiles + zoom crops; tile ↔ full-image coordinate mapping
  models.py         dataclasses: Finding, FixAttempt, PosterResult (+ JSON in/out)
  instructions.py   parse FIX_INSTRUCTIONS-style markdown into known (wrong, right) pairs
  inspect.py        Claude vision: full view + tiles → findings JSON (transcribe, then judge)
  locate.py         pixel-precise word box inside a coarse region: ink mask, line bands, word gaps
  fonts.py          font candidates, size fit by line width, ink color, baseline detection
  retype.py         erase box (sampled background fill) + redraw word/line with PIL
  inpaint_openai.py crop + alpha mask → OpenAI images.edit → paste back (stylized text only)
  verify.py         outside-mask zero-diff, Claude re-read of the crop, style gate score
  report.py         per-poster HTML (JBG dashboard convention) + JSON, batch xlsx summary
```

## Pipeline per poster

1. **Ingest** to a PIL RGB image at native size. Keep the original untouched; work on a copy.
2. **Inspect** (Claude vision, default model `claude-opus-5`, configurable). Send the full poster plus
   overlapping native-resolution tiles. Pass 1 transcribes every text block with a normalized bbox per
   line. Pass 2 judges the transcript: spelling, grammar, facts, consistency, duplicates, safe-zone,
   guardrails. Known errors from the instructions file are injected and must each be located. Each
   finding carries: box name, line text, wrong word, correct word, word index in line, font style
   (`plain` / `script` / `blackletter` / `stylized`), type, confidence 0–1, coarse bbox in full-image px.
3. **Locate**. Crop the coarse bbox, build an ink mask (Otsu), find the line band whose word count
   matches the transcript, split the line at the N−1 widest gaps, pick the word by index. Result is the
   exact word box, the line box, the baseline row, and the ink color.
4. **Fix**, escalating:
   - `retype` if font style is `plain`: erase the word box (fill with median non-ink color of the
     box), calibrate font size so the rendered full line matches the measured line width, draw the
     corrected word at the original x on the detected baseline. If the corrected word does not fit
     before the next word, switch to line mode (erase and redraw the whole line).
   - `inpaint_openai` if `script` / `stylized` / `blackletter`, or if retype failed the gate: square
     crop around the line, alpha mask over the word box only, exact prompt
     ("replace the word X with Y, same font, same color, same size, nothing else changes"), paste back.
   - `higgsfield` (last resort): emit the exact edit prompt to the report and mark NEEDS_HIGGSFIELD.
     The Claude Code session runs it through the Higgsfield MCP because there is no API key.
5. **Verify** after each fix: (a) numpy equality outside the erased boxes, (b) Claude reads a 3× zoom
   of the region and confirms it reads the corrected text with no ghost strokes, (c) style gate: Claude
   scores font/size/color/alignment match to neighbors 0–100; accept at ≥ 85. Fail → next backend.
   After all fixes: full re-inspect; any new finding goes back through the loop (max 3 rounds).
6. **Report**: `<SKU>_QC.json`, `<SKU>_QC.html` with before/after zoom crops per fix and the findings
   table, `<SKU>_FIXED.png` (only when fully clean), `<SKU>_NEEDS_HUMAN.png` otherwise. Batch run writes
   `QC_Summary.xlsx`. Nothing is deleted; intermediates go in `<out>/_work/<SKU>/`.

## Lessons baked in (from the Gettysburg fix log)

- Erase box must cover the whole old glyph run including antialias halo (ghost comma), but must start
  after the previous word's last ink column plus half the gap (swallowed comma).
- Never auto-fit font size to the box height; it oversizes. Fit size to the known full-line width.
- Row height inflated by descenders is not cap height. Baseline comes from the row-density drop.
- Work at the highest-resolution source available. Note the scale factor if the file was shrunk.
- Verify every changed word with a zoom crop, then re-read the whole poster.

## Testing

- Unit tests with synthetic fixtures rendered by PIL (parchment background, Georgia Bold line
  "Gettysburg, Pennsylvaia,"): locate finds N words and the right word box; retype leaves every pixel
  outside the box unchanged; tiles cover the image and map back correctly; instructions parser.
- Inspector and verifier tested with a fake client returning canned JSON.
- Integration (needs keys, run by the reviewer, not CI): Gettysburg `_v3_TOFIX.png` → both errors fixed;
  then the 4 queued civics posters in `Cowork/New civic/JBG_Civics_ChatGPT_ToFix`.

## Out of scope (YAGNI)

Image-quality upscaling for print, listing/lifestyle regeneration, and a GUI. The FINAL Gettysburg is
1011×1556 px, below 11×17 at 300 dpi (3300×5100); upscaling is a separate step.
